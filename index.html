Oʻrnatish

Mac

  1. Nest-mac.zip faylini yuklab oling va ustiga ikki marta bosing. Nest ilovasi paydo boʻladi.
  2. Nest’ni Applications papkasiga torting.
  3. Birinchi ochishda macOS Nest’ni tekshira olmasligini aytadi, chunki Nest App Store’dan emas. System Settings → Privacy & Security boʻlimining pastida Open Anyway’ni bosing.

Windows

  1. Microsoft Edge yoki Chrome’da «Windows’ga oʻrnatish» tugmasini bosing.
  2. Ochilgan sahifada Install’ni bosing (yoki adres qatoridagi oʻrnatish belgisini).
  3. Nest Start menyusida alohida ilova boʻlib turadi va internetsiz ham ishlaydi.

Android

  1. Chrome’da «Android’ga oʻrnatish» tugmasini bosing.
  2. Install’ni bosing yoki menyu ⋮ → Add to Home screen.
  3. Nest ilovalar roʻyxatida paydo boʻladi.

iPhone, iPad

  1. Safari’da «iPhone’ga oʻrnatish» tugmasini bosing.
  2. Pastdagi Share (Ulashish) → Add to Home Screen.
  3. Nest bosh ekranda ilova boʻlib turadi.

Qaydlar har bir qurilmada alohida saqlanadi. Boshqa qurilmaga koʻchirish uchun: Export → Backup (.zip), keyin yangi joyda Restore.

Fayl toʻgʻriligini tekshirish

Yuklab olingan fayl shu yerdagi bilan aynan bir xil ekanini SHA‑256 orqali tekshirish mumkin. Mac’da Terminal’da: shasum -a 256 Nest-mac.zip
